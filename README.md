## Compilación

Desde la carpeta raíz del proyecto, ejecutamos:

```bash
cmake -B build
cmake --build build
```

## Ejecución

Y para ejecutarlo nos metemos a la carpeta build y ejecutamos:

```bash
cd build
./3d
```
